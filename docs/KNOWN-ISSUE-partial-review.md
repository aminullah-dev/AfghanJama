# اشکال باز: تأیید نظارت کلِ سفارش را وارد انبار می‌کند

**وضعیت:** پیدا شده، درست نشده. پیش از تحویلِ نهایی باید حل شود.

## چه اتفاقی می‌افتد

سفارشی که فقط بخشی از عددهایش دوخته شده، هنگام تأیید نظارت **با تعدادِ
کامل** وارد انبار محصول می‌شود. باقی، جنسِ خیالی است که وجود ندارد ولی
می‌شود فروختش.

مثال از دادهٔ واقعی: سفارش «عربی»، کل ۲۰ عدد، ۶ عدد به خیاط سپرده شده.
اگر همان ۶ عدد دوخته و به نظارت فرستاده شود و ناظر تأیید کند، ۲۰ عدد
وارد انبار می‌شود.

## زنجیرهٔ علت

۱. `SewingScreen` دکمه‌ای دارد به نامِ «ارسال به نظارت **(هرچه آماده
   است)**» — یعنی صریحاً ارسالِ جزئی را پیشنهاد می‌کند.

۲. `SewingViewModel.sendToReview` فقط وضعیت را عوض می‌کند و هیچ‌جا ثبت
   نمی‌کند چند عدد واقعاً دوخته شده:

   ```kotlin
   if (o.status == CUT_DONE || o.status == SEWING) {
       repo.changeOrderStatus(o, REVIEW)
   }
   ```

۳. `Repo.approveQc` → `Repo.depositOrderToFinished` تعدادِ کاملِ سفارش
   را با بهای کامل وارد انبار می‌کند:

   ```kotlin
   val totalCost = order.fabricPrice + order.workCost + order.sewingCost
   addFinishedStock(order.designTitle, order.size, order.qty, totalCost)
   //                                              ↑ کلِ سفارش
   ```

## چرا تا امروز دیده نشده

تا وقتی کلِ سفارش یکجا دوخته و فرستاده شود، `order.qty` جوابِ درست است.
اشکال فقط با ارسالِ جزئی خودش را نشان می‌دهد — همان کاری که دکمه
پیشنهادش می‌کند.

## راهِ امنِ موقت

سفارش را فقط وقتی به نظارت بفرستید که **همهٔ** عددهایش دوخته شده باشد.

## آنچه اصلاحِ درست لازم دارد

- تعدادِ واقعاً دوخته‌شده از `sewing_assignments` (سطرهای تکمیل‌شده و
  عددِ تحویلیِ هرکدام) درآید، نه از `order.qty`.
- انبار فقط همان تعداد را بگیرد، با بهای **متناسبِ** همان تعداد — نه
  کلِ بهای سفارش، وگرنه حسابِ «کار در جریان» و «موجودی محصول» از هم
  جدا می‌افتند.
- باقی‌ماندهٔ سفارش در دوخت بماند و بشود بعداً همان مسیر را برایش
  تکرار کرد.
- سندِ حسابداری هم باید همان نسبت را ببرد.

### آزمونی که باید نوشته شود

منطقِ خالص جدا شود (مثلِ `StockForecast` و `Margin`) و این‌ها سنجیده
شوند:

- سفارشِ ۲۰تایی که ۶ عددش دوخته شده → انبار ۶ عدد بگیرد، نه ۲۰.
- بهای واردشده به انبار با نسبتِ ۶/۲۰ بخوانَد.
- بعد از ارسالِ جزئی، ۱۴ عدد هنوز در دوخت بماند.
- دو ارسالِ جزئیِ پشتِ‌هم روی‌هم دقیقاً برابرِ کلِ سفارش شود — نه
  بیشتر، نه کمتر.
- سفارشِ کامل مثلِ امروز رفتار کند (هیچ رفتارِ موجودی نشکند).
