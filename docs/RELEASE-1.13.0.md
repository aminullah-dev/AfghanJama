# خیاط‌یار ۱.۱۳.۰ — داشبوردِ اولویت‌دار، «تحلیل»، «دستیار» و حالتِ تاریک

نسخهٔ قابلیتی روی ۱.۱۲.۱. **دفتر و قراردادِ کارگاهِ وصل عوض نمی‌شود** و هیچ
مهاجرتِ دیتابیسی ندارد — نصبِ تازه روی نسخهٔ قبلی می‌نشیند و دفترِ همان کارگاه
دست‌نخورده باز می‌شود. همهٔ بسته‌ها از یک تگ و یک کامیت (`v1.13.0`) می‌آیند.

**همه‌چیز ۱۰۰٪ آفلاین است** — هیچ قابلیتی به اینترنت وصل نمی‌شود؛ تنها شبکه،
همان اتصالِ محلیِ وای‌فای کارگاه (گوشی‌ها ↔ کامپیوترِ مادر) است.

## تازه‌ها (کامپیوتر)

- **داشبورد — چیدمانِ اولویت‌دار.** کارت‌ها به ترتیبِ اهمیت نوبتی در ستون‌ها
  می‌نشینند: ردیفِ بالا همیشه مهم‌ترین‌ها (هشدار، پیش‌بینیِ پول، وضعِ مالی، پول)،
  و ستون‌ها هم‌قد — فاصله‌های خالیِ قبلی رفت.
- **«تحلیل» (بخشِ تازه).** سود به‌تفکیکِ **مشتری** و **خیاط** (تا حالا فقط بر
  اساسِ محصول بود): ارزشمندترین مشتری‌ها، سودآورترین خیاط‌ها، خلاصهٔ درآمد و
  حاشیه، با فیلترِ بازه. سودِ هر خیاط به نسبتِ دستِ کارش از هر سفارش شکسته می‌شود.
- **«دستیار» (بخشِ تازه، گروهِ «امروز»).** خلاصهٔ کسب‌وکار به زبانِ ساده و پاسخ
  به پرسش‌ها — «پرسودترین مشتری کیست؟»، «پولِ نقد چقدر دارم؟»، «کدام سفارش‌ها دیر
  می‌شود؟»، «کدام مواد رو به اتمام است؟» و… **کاملاً آفلاین**، از روی دفترِ خودت.
- **حالتِ تاریک.** در تنظیمات ← «ظاهر»: روشن / تاریک / پیروِ سیستم.
- **جزئیاتِ سفارش.** زیرِ بهای تمام‌شده، خطِ سود/ضرر و حاشیه، با هشدارِ سرخِ
  «زیرِ بهای تمام‌شده» برای سفارشی که ضرر فروخته شده.
- **مالی ← گزارش.** کارتِ «نقطهٔ سربه‌سرِ این ماه» (وقتی هزینهٔ ثابت ثبت شده
  باشد): چند درصدِ هزینهٔ ثابت پوشیده شده و تا سربه‌سر چقدر مانده.
- ظاهرِ کارت‌ها یک‌دست‌تر شد (کامپوننتِ مشترکِ `AppCard`).

## ساخت و امضا — ویندوز

نصبِ مشتری همان روالِ ۱.۱۲.۱ است؛ گواهیِ خود-امضا از قبل ساخته شده و مشتری
`KhayatYar-signing.cer` را دارد، پس آپدیت بی‌هشدار روی نصبِ قبلی می‌نشیند
(`UpgradeCode` ثابت).

روی کامپیوترِ ویندوز (JDK 17 کامل + WiX 3):

```powershell
git fetch; git checkout v1.13.0
.\tools\windows-signing\3-ساخت-و-امضا.ps1
```

خروجی: یک `KhayatYar-1.13.0.msi` که `KhayatYar.exe`ِ داخلش امضا شده و
`UpgradeCode`ش با نصبِ قبلی یکی است. همین فایل را به مشتری بده؛ روی ۱.۱۲.۱ او
می‌نشیند و دفترش دست‌نخورده می‌ماند.

> اگر سرِ اجرا خطایی داد، متنش را بفرست تا درست شود (اسکریپت‌ها روی مک نوشته
> شده‌اند و روی ویندوزِ واقعی کمتر آزموده شده‌اند).

## مک و آیفون

ساختِ امضا/notarizeِ مک همان روالِ `tools/macos-signing/sign-and-notarize.sh`
است؛ آیفون از همین تگ ساخته می‌شود. این نسخه برای کاربرِ فعلی (ویندوز) است.
