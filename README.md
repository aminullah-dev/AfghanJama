# ⛔ این شاخه کهنه است — ادغامش نکنید

**شما در `claude/windows-parity` هستید. کارِ زنده در `main` است.**

آخرین کامیتِ این شاخه **۴ اوت ۲۰۲۶** است. از آن روز `main` جلو رفته
و اینجا سرِ جایش مانده.

## اگر ادغامش کنید چه می‌شود

`main` **۳۷٬۲۳۲ خط در ۲۰۰ فایل** از دست می‌دهد:

    git diff --stat main claude/windows-parity
    → 200 files changed, 1569 insertions(+), 37232 deletions(-)

## چرا فریب‌دهنده است

گیت‌هاب بالای همین صفحه می‌نویسد این شاخه **۲۲۳ کامیت جلوتر** از
`main` است. آدم می‌بیند و فکر می‌کند ۲۲۳ کارِ نرفته اینجاست.

این‌طور نیست. محتوای آن کامیت‌ها در `main` هست؛ فقط شناسه‌هایشان فرق
دارد چون تاریخچه یک بار فشرده شد. **عددِ کامیت را باور نکنید،
`git diff --stat` را باور کنید.**

## کارِ درست

    git checkout main

و این شاخه را پاک کنید — چیزی از دست نمی‌رود:

    git push origin --delete claude/windows-parity

اگر روزی پشیمان شدید، از همان شناسه برمی‌گردد:

    git push origin b34337f:refs/heads/claude/windows-parity
